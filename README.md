## 📝 Descrição
O sistema é uma ferramenta de auxílio para analistas de suporte, ele permite:
* Cadastro e Login de Analistas (com validação de e-mail e senha)
* Abertura de chamados com níveis de urgência
* Visualização em tempo real de tickets salvos no banco de dados
* Atualização de status (Resolver chamado)
* Exclusão definitiva de registros (CRUD Completo)

## 🛠️ Tecnologias Utilizadas
* **HTML5 / JavaScript** (Lógica assíncrona com Fetch API).
* **Tailwind CSS** (Estilização e Responsividade).
* **Supabase** (Backend e Banco de Dados PostgreSQL).
* **SweetAlert2** (Alertas personalizados).

## 🗄️ Banco de Dados
O script SQL para criação das tabelas `analistas` e `chamados` está disponível no arquivo `comandos.sql` deste repositório.
